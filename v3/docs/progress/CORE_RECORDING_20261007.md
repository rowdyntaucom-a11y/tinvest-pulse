# QVANIX Core — real-device recording pass 2026-10-07

Запись мобильного Core показала три повторяющихся UX-проблемы: дублирующийся плавающий переход наверх рядом с системным/touch affordance, заметное затемнение/blur при открытии селектора глубоких разделов и повторные промежуточные состояния при переходах между «Обзор / Календарь / Глубина».

Патч:
- отключает собственную плавающую кнопку «наверх» на coarse-pointer устройствах, оставляя её на desktop;
- ограничивает scroll-state обновления одним animation frame;
- убирает full-screen backdrop blur у мобильного selector sheet;
- гидратирует календарь и глубокий доход из общего тёплого payout-cache;
- заранее подгружает глубокие Core-модули после подтверждения портфеля;
- сохраняет позицию чтения отдельно для подрежимов «Доходность» и «Выплаты»;
- добавляет keyboard/tab semantics к task rails;
- увеличивает читаемость вторичных подписей и безопасный нижний отступ под fixed navigation.

Финансовая семантика и расчёты не изменяются.
