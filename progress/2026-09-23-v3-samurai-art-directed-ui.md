# QVANIX v3 — Samurai art-directed UI

Date: 2026-09-23
Base: `992e54022cbf9f84a585404b8fc0a353688ab0bf`.

## Why
Real Samsung review rejected the prior shell work as essentially one interface with different wallpaper, with Samurai specifically looking poor on Home and inner workspaces. The new rule is art-first: widgets occupy quiet zones around the artwork rather than laying a shared card grid over it.

## Samurai rebuild
- Home is now an asymmetric cinematic stage: artwork/right side remains open; the portfolio answer is a left command scroll; primary metrics form a low data rail with TWR as the anchor.
- Inner workspaces use an offset scroll grammar: narrow ink heading, left-anchored hero, right-shifted metric register and sharp lacquer content surfaces.
- Navigation is a blade rail with a copper active marker instead of a filled generic tab.
- Copper/jade rules, paper/ink typography and square-cut geometry replace the generic rounded-card language.
- Mobile has a dedicated composition rather than shrinking desktop.

## Boundaries
No new artwork or fal.ai spend. Existing production Samurai art remains the composition source. No finance/data/API/Data Trust/Pulse/DNA runtime changes. No new animation, filters, network calls or live blur.
