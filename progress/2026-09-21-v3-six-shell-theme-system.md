# QVANIX v3 — six-shell theme system

Date: 2026-09-21

## Basis
The supplied theme-demo document defines six identities (Core, Horizon, Carbon, Aurora, Minimal, Samurai) and a useful invariant: components should consume shared theme semantics instead of accumulating theme-specific business logic. QVANIX keeps its richer material-world approach while completing that six-shell set.

## Implemented
- Existing CORE, HORIZON, CARBON and SAMURAI remain materially distinct.
- AURORA adds an expressive northern-light glass world with cyan/violet atmospheric depth.
- MINIMAL adds a quiet analytical light world with restrained geometry, no decorative atmosphere and low visual noise.
- Both new shells participate in the same persisted preference contract and canonical workspace selector.
- Financial methodology, data trust, navigation and Living World progression are unchanged.
- Reduced-motion remains fail-safe for animated atmosphere.
