The latest Samsung review showed shell identity and composition are now materially different, but background art can still compete with headings and key values. Cosmos/Neon remain dark in the information plane; Samurai can place warm/high-energy art under copy; light shells need separation without returning to generic glass cards.

## Pass
Added a lightweight final reading-field grammar that preserves each shell's composition:
- Samurai: dark ink panel + warm blade rule and stronger neutral copy.
- Cosmos: brighter technical information plane + cyan instrument rail.
- Neon: opaque violet poster strip + electric top rail.
- Zen: paper veil + hairline ink rules, no dark glass.
- Nord: frost-solid reading slab + stronger slate ink.
- Imperium: ivory ledger header + bronze double rule.

Key financial values use tabular numerals but no calculation/data semantics changed. Mobile raises reading-field opacity while keeping artwork peripheral. No new assets, network calls, filters, backdrop blur, animation or fal.ai spend.
