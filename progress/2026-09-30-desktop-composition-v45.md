# QVANIX Desktop Composition v45 — 2026-09-30

This patch is based on the user's real PC recording after v44. The responsive foundation worked structurally, but the desktop view still looked like a narrow mobile interface placed inside a large monitor: too much empty space, typography too small, side navigation too weak, and dense financial workspaces did not exploit width.

## Desktop overview
- Recompose Overview into a desktop cockpit.
- Large Capital/history chart becomes the primary pane.
- Allocation + “Сейчас” become a compact right-side rail.
- Assets move to a full-width table below the cockpit.
- Phone/tablet markup remains usable without this desktop grid.

## Desktop canvas and navigation
- Desktop canvas expands from 1280 to 1380 px, and to 1480 px on very wide screens.
- Left navigation rail expands to 228 px with stronger active/hover states and a visible section label.
- Main content reserves rail space instead of sitting in a narrow centered column.
- Desktop header and page titles use a larger scale.

## Desktop financial density
- Asset tables use wider identity/value/P&L columns.
- Overview, Result and Income typography is increased materially.
- Result lead, truth cards and history chart get desktop-specific scale.
- Analytics KPI cards, market rows and workspace tabs are enlarged.
- Asset detail uses a three-column information grid.

## Professional workspaces
- Analytics navigation becomes a 3-column desktop grid.
- Market workspace navigation uses 3 columns.
- Professional tool groups use 3 columns.
- Dense modules remain vertically scrollable; no information is removed.

## Guardrails
No financial formula or data contract changed. No trading capability added. No fabricated data. Phone behavior is intentionally preserved. Living World/DNA remains frozen.
