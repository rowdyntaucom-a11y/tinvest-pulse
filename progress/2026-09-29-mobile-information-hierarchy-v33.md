# QVANIX Mobile Information Hierarchy v33 — 2026-09-29

## Basis
The latest ~1:20 Samsung recording confirmed that v31/v32 fixed portfolio truth and removed the worst legacy visual breaks. The next limiting factor is no longer data delivery or color skinning: deep analytics and tools expose too many equally weighted cards at once.

Canonical rule reinforced in this pass:
**FIRST SCREEN MUST ANSWER. DEPTH MAY SCROLL.**

## Analytics hierarchy
- The light Core quick analytics layer is now explicitly labelled and separated from professional depth.
- Quick tabs are renamed around the user question: Structure / P&L / Risk / Pro.
- The quick layer explains what each mode answers instead of presenting four equal technical tabs.
- The workspace selector and local analytics selector stay sticky on mobile so the two navigation levels remain visually distinct.

## Progressive depth
No analytics were deleted.
- Return: TWR / volatility / Sharpe / Sortino stay immediately visible; rolling-window detail moves behind an intentional disclosure.
- Risk: MaxDD / volatility / effective positions / asset-class count stay immediately visible; VaR/CVaR tail detail and per-asset risk/correlation contribution become separate disclosures.
- Benchmark: portfolio / IMOEX / excess / paired sample stay immediately visible; Tracking Error / Information Ratio / beta / correlation become secondary disclosure.
- Mobile typography floors are raised for captions and explanatory copy.

## Tools workbench
The professional toolbox is no longer one flat module rail.
- Management: Rebalance + Report.
- Scenarios & research: Portfolio Lab + Futures (+ Market when the shared toolbox is used outside light Core).
- A “Now” focus card explains what the selected tool is for before the full workspace opens.
- Only one selected tool renders at once.

## Boundaries
No financial formula or source contract changed.
No trading, order entry or personalized buy/sell guidance.
No DNA / Living World work.
Active product remains light QVANIX Financial Core.
