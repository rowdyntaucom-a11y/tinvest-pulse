# Zen signature shell — 2026-09-24

## Scope
Zen (`horizon`) received its first complete signature-system pass after Samurai, Cosmos, Nord/Aurora and Neon.

## Direction
Zen is a quiet contemplative garden instrument, not a green recolor. Its material language is dark paper, stone, mist, water rings, moss/jade and restrained warm-gold accents. Geometry deliberately contrasts the harder Samurai/Neon systems through asymmetric soft corners, sparse chrome and larger visual breathing space.

Workspace character remains distinct inside one world:
- Home: calm paper/stone command surface with water-ring signature.
- Assets: moss-ledger treatment.
- Analysis: jade observation room.
- Income: restrained warm-gold treasury accent.
- Goal: water/jade path treatment.
- Navigation: quiet jade focus marker rather than a luminous rail.

## Motion / mobile
Atmosphere uses slow opacity/transform breathing and mist drift. Mobile reduces atmospheric intensity. `prefers-reduced-motion` disables both signature animations.

## Guardrails
Presentation-only CSS plus stylesheet wiring. No finance semantics, trust/fail-closed behavior, broker access, DNA ownership/runtime, navigation model or security boundary changed. Canonical rule remains **FIRST SCREEN MUST ANSWER. DEPTH MAY SCROLL.**
