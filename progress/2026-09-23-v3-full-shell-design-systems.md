# QVANIX v3 — full shell design systems

Date: 2026-09-23
Starting main: `5598d2553d6b9f28a91c30eb29444581efe57a74`.

## Decision
Latest Samsung feedback overrides the previous Living World priority: pause further DNA scene work and return to the main workspaces. The six shells must read as six complete interface systems, not one dashboard with different wallpaper.

## Large pass
Added a final presentation boundary shared by Home, Portfolio, Analytics, Income, Goal and Asset Workspace. Each shell now owns typography, card geometry, border/shadow language, hero treatment, navigation shape and density rhythm:
- Samurai — lacquer/paper, editorial serif, blade rules and cut asymmetric corners.
- Cosmos — compact technical console, uppercase labels, diagonal/clipped hero panels and orbital rails.
- Neon — bold rounded synth/arcade modules with electric header rails.
- Zen — airy editorial paper, hairline separators and deliberately flat surfaces instead of glass tiles.
- Nord — Scandinavian utility, cool solid panels, generous radius and strong sans hierarchy.
- Imperium — archival financial ledger, sharp ivory geometry, bronze double rules and authoritative serif headings.

The same verified data and information architecture remain intact. This pass adds no generated art, no network dependency, no animation and no blur on mobile.

## Guardrails
DNA/Pixi ownership is untouched. No financial methodology, broker/API, Data Trust, Pulse, formula, fal.ai or credential changes. Samsung/mobile no-backdrop-filter safeguard remains explicit. Regression coverage locks all six structural identities and final stylesheet ordering.
