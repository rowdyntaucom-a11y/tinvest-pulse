# 2026-09-24 — Samurai secondary parity

Evidence: Samsung recording `1000031561.mp4`.

## Finding
The Goal pass materially improved Samurai, but Assets / Analysis / Income still lagged Cosmos. The issue was not missing decoration; it was composition. Each chapter still stacked a large title, fail-closed status and a wide instrument over the same Ronin artwork, leaving the character/world as background rather than part of the interface.

## Correction
- Generic untrusted page headers and duplicate workspace chrome are hidden for Samurai Assets / Analysis / Income.
- First viewport is now an open Ronin scene.
- Chapter identity is a small asymmetrical plate.
- Fail-closed explanation is a compact side note.
- Each chapter keeps one distinct side instrument:
  - Assets = formation map;
  - Analysis = tactical scope;
  - Income = treasury ledger.
- Central character corridor remains open.
- The existing depth cue is now a real button and smooth-scrolls to verification detail.
- Verification route, retry action and fail-closed explanation live in the second viewport.
- No financial values or broker semantics changed.
- No new heavy blur/filter cost on mobile.

## Direction
Cosmos is the current integration benchmark, not a geometry template. Samurai must reach equivalent product depth with its own visual grammar: lacquer, ink, gold/red accents, asymmetry, path/formation/scope metaphors and visible world art.
