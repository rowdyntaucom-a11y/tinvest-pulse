# QVANIX Cosmos — first-screen cue + functional depth correction

Date: 2026-09-24
Real-device evidence: Samsung recording `1000031539.mp4`.

## User finding
1. The Home smooth-scroll arrow existed, but was below the initial viewport and therefore failed its purpose.
2. Secondary Cosmos tabs visually looked like "one widget per tab", especially in fail-closed states.
3. This presentation contradicted the product direction: QVANIX must preserve deep portfolio functionality comparable in breadth/usability to Snowball while keeping QVANIX's deterministic analytics and visual identity.

## Correction
- Home arrow is moved into the first art viewport, above fixed navigation, and scrolls away with the scene.
- Fail-closed Assets / Analysis / Income now show four truthful capability modules over art-safe regions:
  - Assets: holdings, classes, concentration, asset detail.
  - Analysis: return, risk, benchmark, structure.
  - Income: received income, calendar, sources, coverage.
- Missing values remain unavailable (`—`); no fake data is introduced.
- Goal shows a four-module deck when the target or trusted data is missing: capital, target, progress, scenarios.
- The source/retry gate remains, but becomes a secondary control below the capability deck instead of monopolizing the first screen.

## Product rule
Cosmos visual composition must never reduce product depth. The first screen answers; deeper workspaces scroll. Full analytical depth remains in the existing canonical workspaces and drill-downs.
