# QVANIX · autonomous reporting rule

Date: 2026-09-14

The user explicitly asked autonomous work to continue without repeated confirmation prompts.

When the user next asks what has been done, the report must include:
- completed project areas in numbered points;
- remaining project areas in numbered points;
- an overall completion percentage;
- an overall remaining percentage;
- percentages should be based on the current approved project roadmap/audit rather than commit count or elapsed time;
- gated/legal/later items must be identified separately so the percentage does not imply they are immediately implementable.

This reporting rule is part of project continuity and should be preserved across chats.
