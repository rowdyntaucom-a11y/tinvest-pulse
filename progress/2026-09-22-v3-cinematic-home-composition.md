# Cinematic Home composition

Real-device video after #536 showed the world still reading as wallpaper behind dashboard chrome. This pass changes composition rather than adding another visual skin.

- Scene begins at viewport top and owns the first-screen stage.
- Hero container loses the large glass rectangle; canonical portfolio value moves to a local legibility island.
- Theme artwork remains visible around the data instead of being washed out by full-card blur.
- Samurai/Cosmos use controlled dark local plates; Light/Aurora use translucent bright plates without milky full-scene haze.
- Individual mobile focal positions preserve right-side subjects and left-side financial safe zone.
- Financial contracts/calculations/navigation unchanged.
