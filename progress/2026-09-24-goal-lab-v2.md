# 2026-09-24 — Goal Lab v2

## Trigger
Real Snowball Goal screenshots showed a product gap: QVANIX had a visually stronger themed Goal first viewport, but the deep goal setup was less flexible and the scenario layer was hidden behind detailed mode/trusted data.

## Direction
Keep the Cosmos first viewport atmospheric and concise. A visible animated arrow leads into a deep planning workspace below it.

## Goal Lab v2
- Goal type inside the scenario builder:
  - target capital;
  - desired passive income, converted to an equivalent capital only from the user's own payout-yield assumption.
- Target capital can be edited from the deep lab and stays synchronized with the first-screen Goal command.
- Horizon: 1–50 years.
- Monthly contribution.
- User-authored price-return assumption.
- User-authored dividend/coupon yield assumption.
- Reinvest payouts toggle.
- Inflation-adjust-target toggle with explicit inflation input.
- Grow-contributions toggle with explicit annual growth input.
- Optional benchmark-return scenario.
- Optional deterministic alternative scenario:
  - solves the minimum monthly contribution needed to reach the target under all other user assumptions;
  - no hidden return assumptions;
  - result may be applied back to the contribution field.
- Annual scenario chart.
- Annual result table.
- Existing historical block-bootstrap remains a separate tab and remains explicitly non-predictive.
- Scenario settings persist locally, but broker credentials and broker data do not.

## Data-honesty boundary
- Missing target, current capital, or required assumptions never receive default financial values.
- Empty inputs remain empty.
- Forward-looking output is always labelled as a scenario, not a forecast or promise.
- Historical bootstrap remains separate from user assumptions.
- No buy/sell action or automatic trading.

## UX
- First screen answers.
- Deep Goal Lab scrolls.
- The Goal Lab arrow is visible in the first Cosmos viewport and uses smooth scroll with reduced-motion fallback.
