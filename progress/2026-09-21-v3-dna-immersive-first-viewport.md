# QVANIX v3 — DNA immersive first viewport

Date: 2026-09-21

## Real-device evidence
The first live Samsung capture confirmed that DNA was technically integrated, but product chrome, a separate header and explanatory copy consumed vertical space before the scene. The Pixi world read like an embedded technical panel rather than the primary experience.

## Product decision
DNA gets its own immersive composition under the shared QVANIX shell. The world is the hero; explanatory/product depth follows it. This intentionally differs from analytical workspaces and follows the canonical DNA exception in the workspace scroll policy.

## Changes
- Merge DNA identity, title and trust context into the world hero instead of stacking a separate header above it.
- Grow the real mobile scene to the first viewport while preserving shared shell/navigation.
- Overlay phase/context and a compact three-part HUD inside the world.
- Hide renderer diagnostics on narrow phones.
- Add a compact story/action bridge and move methodology/progression explanation below the immersive scene.
- Preserve the canonical Pixi renderer, local time phase, neutral weather and fail-closed level 1 / XP 0 progression.

## Boundary
This pass does not claim the procedural scene art is final. It fixes composition and interaction hierarchy first. Higher-fidelity reviewed art/character assets can replace canonical asset slots later without creating a second renderer.

No financial methodology, broker data, trust classification or automatic trading behavior changed.
