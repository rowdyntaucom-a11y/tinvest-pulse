# tinvest-pulse v7.0 — PULSE 2.0 / Portfolio DNA

PULSE теперь диагностирует не только рыночный фон, но и структуру самого портфеля.

- DNA Score по шести компонентам: баланс, концентрация, стабильность, денежный поток, рост и диверсификация;
- фактический расклад акций / ОФЗ и облигаций / резерва;
- сравнение структуры с целевой моделью 50/50;
- контроль крупнейшей позиции и концентрации капитала;
- ключевые риск-узлы и вклад крупнейших активов;
- денежный поток и пассивный доход;
- более компактный Quiet State в FUND INTEL;
- «Крупнейшая позиция» вместо ошибочного «главного фактора» при отсутствии событий;
- промежуточный режим «НАБЛЮДАЕМ» для качественных материалов, которым пока не хватает фактической плотности до полноценного события;
- сохранён Event Understanding v6.9: движение котировок без бизнес-фактора не считается самостоятельным событием.

Приложение остаётся информационно-аналитическим: не исполняет сделки и не формирует команды купить/продать.
