# tinvest-pulse v6.9 — Event Understanding

INTEL не только фильтрует новостной шум, но и проверяет, есть ли в публикации реальный бизнес-факт.

- оценка релевантности новости конкретной позиции;
- оценка качества источника и свежести;
- классы ФАКТ / СИГНАЛ / ФОН / ШУМ;
- ШУМ не попадает в основные карточки;
- отдельная проверка EVENT UNDERSTANDING;
- ценовое движение без найденного бизнес-фактора не считается полноценным событием;
- извлечение конкретных фактов и числовых маркеров из доступного текста публикации;
- проверка причинно-следственной связи события с бизнесом компании;
- более предметные блоки «Что произошло», «Почему это важно» и «Что изменит оценку»;
- режим ТИХО, если по позиции нет достаточно качественного и содержательного события;
- согласованные счётчики событий и тихих позиций в FUND INTEL.

Приложение остаётся информационно-аналитическим: не исполняет сделки и не формирует команды купить/продать.
