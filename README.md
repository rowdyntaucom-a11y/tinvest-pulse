# tinvest-pulse v6.8 — Quality Engine

INTEL теперь фильтрует новости до показа пользователю.

- оценка релевантности новости конкретной позиции;
- оценка качества источника и свежести;
- классы ФАКТ / СИГНАЛ / ФОН / ШУМ;
- ШУМ не попадает в основные карточки;
- штраф для подборок с множеством тикеров и generic «идей»;
- режим ТИХО, если по позиции нет достаточно качественного события;
- сила и надёжность считаются только по прошедшим фильтр публикациям;
- карта внимания показывает и тихие позиции.

Приложение остаётся информационно-аналитическим: не исполняет сделки и не формирует команды купить/продать.
