# tinvest-pulse v7.1 — CASH FLOW / Explainable DNA

PULSE показывает не только структуру портфеля, но и оценку реального денежного потока после НДФЛ.

- NET cash flow: начислено → оценочный НДФЛ → на руки;
- 13% до 2,4 млн ₽ инвестиционной налоговой базы и 15% на превышение;
- чистый средний доход в месяц, год и чистая доходность на капитал;
- 12-месячный NET-календарь на базе текущего среднего пассивного потока;
- Explainable DNA: тап по гену объясняет, что влияет на его балл;
- концентрация оценивается отдельно, с ориентиром ядра около 20%;
- сохранены Portfolio DNA v7.0 и Event Understanding / FUND INTEL.

Налоговый расчёт информационный и оценочный. Фактически удержанный налог может отличаться из-за ИИС, льгот, вычетов, налогового резидентства, зачётов и других налоговых баз. Приложение не является налоговой консультацией и не исполняет сделки.
